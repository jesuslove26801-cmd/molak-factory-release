# 몰락경제사공장 설치 파일

[최신 버전 받기](https://github.com/jesuslove26801-cmd/molak-factory-release/releases/latest/download/molak-factory-setup.exe)

1. molak-factory-setup.exe 를 받아 실행하세요.
2. 'Windows의 PC 보호' 창이 뜨면 **추가 정보 → 실행** 을 누르세요.
3. 검은 창에서 Enter 를 누르면 설치되고, 바탕화면에 **몰락경제사공장** 바로가기가 생깁니다.

- 필요: Windows 10(1803 이상)/11, 빈 공간 3.5GB
- 사용하려면 사용권 키가 필요합니다.
